# DevOps

Репозиторий-портфолио: собираю здесь практику по всем ключевым направлениям DevOps —
от основ Linux и сетей до Kubernetes и мониторинга. Веду параллельно с системной
подготовкой, но не с нуля — часть опыта в DevOps уже есть,
здесь структурирую и закрепляю его через реальные задачи и pet-проекты.

## Автор
Ефимов Владислав

## Структура

| Папка | Тема |
|---|---|
| `linux/` | Администрирование Linux: процессы, права, systemd, диагностика |
| `networking/` | Сети: TCP/IP, DNS, HTTP(S), Nginx |
| `scripts/` | Bash и Python для автоматизации |
| `docker/` | Dockerfile, docker compose, многоступенчатые сборки |
| `ci/` | CI/CD: GitHub Actions, GitLab CI, Jenkins |
| `ansible/` | Плейбуки и роли для настройки серверов |
| `terraform/` | Инфраструктура как код (Yandex Cloud / локально) |
| `k8s/` | Kubernetes: манифесты, Helm-чарты |
| `monitoring/` | Prometheus, Grafana, Alertmanager, Loki |

## Сквозной проект

`todo-app` — приложение, которое проходит через весь путь: контейнеризация → CI/CD →
деплой в Kubernetes → мониторинг. Финальная версия — в `k8s/` и `ci/`.

## Прогресс

Обновляю по мере прохождения тем — коммиты отражают реальный ход работы.
